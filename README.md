# 🧠 Nexus StudyGPT Pro

AI-Powered Learning & Research Platform built with Streamlit, LangChain, and Groq.

## Features

- 📚 Comprehensive Study Notes
- 🧠 AI-Powered Knowledge Synthesis
- 📝 Flashcard Generation
- ❓ Quiz Generation
- 🔍 Wikipedia Research Integration
- 📄 PDF & Document Analysis
- 🎯 Exam-Oriented Learning
- 💻 Programming Examples & Explanations

## Tech Stack

- Streamlit
- LangChain
- Groq LLMs
- Python
- Pandas
- ReportLab
- OpenAI SDK

## Installation

```bash
pip install -r requirements.txt
streamlit run app.py
```
